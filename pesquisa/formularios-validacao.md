# Formulários de validação da ideia (2026-11-07)

Enviados no grupo SW ITAPEMA. Cada um tem 5 perguntas obrigatórias: 4 de alternativa (com "Outro" para escrever quando faz sentido) e 1 aberta.

## Investidores, aceleradoras e mentores

Link: https://docs.google.com/forms/d/e/1FAIpQLSellYyI60b0imkzNEcxyD_F5geqbmjccue2fO_PXNCLmMEhYg/viewform

1. Qual é o seu perfil? Investidor anjo / Fundo de venture capital / Aceleradora ou incubadora / Empresa do setor de turismo / Mentor ou especialista / Outro
2. O problema (o turista não sabe o que fazer no destino e a informação está espalhada) é relevante para você? Muito relevante / Relevante / Pouco relevante / Não é relevante
3. Qual modelo de receita parece mais promissor? Assinatura de destaque para comércios / Comissão por cliente que chega pelo app / Clube de descontos para turistas / Parcerias com prefeituras e secretarias de turismo / Outro
4. O que você precisaria ver para investir? (várias) Turistas usando o app na temporada / Comércios pagando pelo destaque / Parceria com prefeitura ou associação comercial / Time técnico completo / Plano para outras cidades do litoral / Outro
5. Que conselho, dúvida ou crítica você tem sobre o Partiu? (aberta)

## Turistas (clientes)

Link: https://docs.google.com/forms/d/e/1FAIpQLSdsu_tTCy22HFfJREbiRi3kqSU1h0P1SZvOvl_jrZeFY5Re4w/viewform

1. Com que frequência você viaja para o litoral? Mais de 3 vezes por ano / 2 a 3 vezes por ano / 1 vez por ano / Raramente
2. Quando chega num destino, o que mais faz você perder tempo? Decidir onde comer / Decidir o que fazer / Achar algo aberto perto / Saber quanto vou gastar / Outro
3. Você usaria um app que mostra o que está aberto perto de você, na hora? Sim / Talvez / Não
4. Qual recurso você mais usaria? (várias) Sugestões do que fazer agora / Roteiro do dia pronto / Plano B quando chove ou lota / Descontos em comércios locais / Outro
5. O que faria você usar o Partiu na sua próxima viagem? (aberta)
